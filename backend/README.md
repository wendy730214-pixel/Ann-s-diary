# 小日子家庭同步

這個 Apps Script 後端只使用目前指定的「家庭 Google 試算表」。前端由原本的 GitHub Pages 網址提供，家庭資料不會寫進公開儲存庫。

## 首次設定

1. 在指定試算表開啟「擴充功能 → Apps Script」，將 `Code.gs` 貼到程式編輯器並儲存。
2. 在手帳的「家庭設定 → 第一次設定家庭管理者」產生管理者連線碼，私下保存。
3. Apps Script「專案設定 → 指令碼屬性」新增 `ADMIN_BOOTSTRAP_TOKEN`，值為該連線碼。可選填 `ADMIN_NAME`、`FAMILY_NAME`。
4. 選擇 `setupFamily` 執行一次，並由試算表擁有者完成 Google 授權。它只新增所需分頁；同名分頁有其他內容時會停止。初始化後刪除 bootstrap 屬性，只保存連線碼雜湊。
5. 「部署 → 新增部署 → 網頁應用程式」：執行身分選「我」，存取權選「所有人」。這讓家人不用登入 Google 也能使用；所有資料操作仍須通過個別連線碼驗證。試算表本身不需公開。
6. 將部署的 `/exec` 網址及管理者連線碼填入手帳的「家庭設定」。看到「已同步到 Google 試算表」才代表驗證成功。
7. 管理者在「邀請家人」建立各自的連結。自己的另一台裝置使用「複製我的連線到另一台手機」。持有連結的人可讀取家庭資料，請私下保存；可停用其他成員的連線碼。

## 使用與維護

- 日記、回覆、約定、撲滿和願望請在手帳中新增或修改。試算表的內容分頁由「同步紀錄」產生，直接改分頁不會回寫到手帳，且下次同步可能被更新。
- 原本的個人紀錄保留在各自裝置。只有按「將這台手機的舊紀錄加入家庭」並確認後才會共用。
- 家庭模式先將變更保存在本機待同步佇列，有網路後上傳；使用中約每 20 秒更新，也可按「重新整理」。
- 相同紀錄被同時修改時，不會直接覆蓋另一個人的內容。請先下載待同步備份，再處理同步問題。撲滿餘額不足也會保留待處理內容。
- 避免直接修改「家庭成員」或「同步紀錄」分頁，並定期自行備份整份試算表。
- 更新後端程式後，必須在 Apps Script「管理部署」建立新版本，既有 `/exec` 網址才會使用更新內容。
- 更新 PWA 後，關閉所有手帳視窗再重新開啟，讓新離線版本生效；不要清除瀏覽器資料，以免移除尚未同步的內容。

## 驗證

`node outputs/verify-family.cjs` 使用記憶體中的假試算表，驗證跨裝置日記與回覆、角色權限、版本衝突、撲滿防超支、重試不重複、離線重開及連線碼保護。它不會讀寫真實 Google 試算表。
